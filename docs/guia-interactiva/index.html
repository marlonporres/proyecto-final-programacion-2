Esta web explica el proyecto. La aplicación Android original está hecha con Java y XML; sus pantallas no son una página HTML.

      03 / EL MISMO REGISTRO

      Dos pantallas.
      Una misma base.

      La orden que Android guardó puede recuperarse desde escritorio. Aquí la conexión es directa: Escritorio → JDBC → SQL Server.

      Completa la simulación y pulsa «Consultar la base». Verás el mismo cliente, productos y total.

      ¿Y cuándo baja el inventario?

      Crear, editar o cancelar una orden no descuenta existencias. La salida física ocurre al confirmar el despacho en escritorio. Son dos operaciones distintas del sistema.
